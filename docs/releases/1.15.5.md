## DeepSeek++ More 1.15.0

该更新不仅提升了原生流式渲染稳定性，还重构了本地 API 中转与 Native Host 安装体验，强化了右键快捷提问，并在侧边栏对话中彻底隐藏工具 XML 标签以增强沉浸感。

### 主要变化

- **内联智能体交付升级**：最终回答改由 DeepSeek 页面原生渲染，mermaid/xychart 图表卡片直接展示。
- **开放 API 与中转升级**：新增跨平台 NPM 包 `deepseek-ppmore-ext-apirelay`，一键部署中转守护进程，完善连通性监控。
- **快捷提问 (Ask)**：修复全局右键菜单“问问 DeepSeek”的触发逻辑限制；支持直接唤出悬浮对话框。
- **UI 体验增强**：侧边栏对话流式输出彻底过滤工具执行的 XML 标签；针对 Expert Mode 深度思考模式独家绕过网址链接屏蔽。
- **推理过程展示**：逐轮捕获并展示思考过程，完成后自动折叠为「思考 · 第 N 步」条目；最终回答完整展开。
- **重生成授权修复**：原生 regenerate 工具调用授权修复，仅成功执行过的调用作为授权证据，拒绝或中断的调用不再扩大授权范围。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。
